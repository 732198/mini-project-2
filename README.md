# Personal Finance Dashboard

A lightweight, browser-based personal finance tool built with vanilla JavaScript.
No login. No app to download. Just open it and start tracking.

---

## What It Does

Log your expenses, set monthly budget limits by category, and see a live
breakdown of what you've spent versus what you planned.

---

## How to Use

1. Set a monthly budget for each category (Food, Transport, Housing, etc.)
2. Log an expense by entering an amount, category, and optional note
3. Watch your totals update in real time
4. Delete individual entries or reset everything for a new month
